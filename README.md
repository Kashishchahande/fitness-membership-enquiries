# FitLife Fitness Centre — Digital Marketing Project

A responsive static website for the project **“Increasing Membership Enquiries for Fitness Centre”**.

## Files
- `index.html` — page content and project sections
- `style.css` — responsive design and styling
- `script.js` — copy buttons for sample social media captions/messages

## Before submitting
1. Open `index.html` in a browser to preview the website.
2. In `index.html`, replace `[Add your fitness centre location]`, `[Add phone / WhatsApp number]`, `[Your Name]`, and `[Your USN]` with your own details.
3. Update the sample business details and offers to match your actual project.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example: `fitness-membership-enquiries`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will display your live website link on the Pages settings screen.

The final link will generally look like:
`https://YOUR-USERNAME.github.io/fitness-membership-enquiries/`

This package does not create or publish a repository inside your personal GitHub account automatically.
