# FitZone Fitness Centre — Digital Marketing Portfolio

A responsive, static website inspired by the portfolio layout in the supplied reference images. Topic: **Increasing Membership Enquiries for a Fitness Centre**.

## Files
- `index.html` — portfolio sections and content
- `style.css` — responsive styling
- `script.js` — small navigation interaction

## Run on your computer
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser. No Python installation is needed.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `fitness-membership-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. The website URL will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/fitness-membership-portfolio/`

Your repository URL will be:
`https://github.com/YOUR-GITHUB-USERNAME/fitness-membership-portfolio`

Replace `YOUR-GITHUB-USERNAME` with your real GitHub username. These are URL templates, not an already-created repository.
